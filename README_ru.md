# Wasmee — Движок Durable WebAssembly

Wasmee — это высокопроизводительная изолированная среда выполнения WebAssembly (песочница), разработанная на Rust поверх Wasmtime. Спроектирован для высокоплотных отказоустойчивых вычислений с микросекундным временем запуска и нативной поддержкой снапшотов состояния (контрольных точек).

## Производительность и нагрузочное тестирование

Wasmee спроектирован для достижения максимальной пропускной способности. Поскольку выполнение гостевого Wasm-модуля происходит полностью в памяти (in-memory) хост-процесса, скорость работы превышает **25 000+ RPS** на одно ядро процессора.

При работе через HTTP лимитирующим фактором становится пропускная способность сети и сериализация JSON. Благодаря оптимизированной Base64-сериализации, движок выдает **1 250+ RPS** напрямую через HTTP-интерфейс, генерируя **3.6 ГБ/с** сетевого трафика изменений памяти.

### Локальный запуск нагрузочных тестов

Вы можете запустить бенчмарки Wasmee локально с помощью `k6`.

1. **Сборка и запуск демона Wasmee**:
   ```bash
   # Сборка хост-демона
   cargo build --release
   # Сборка гостевого Wasm-модуля
   cargo build --target wasm32-wasip1 --release --package wasmee-guest
   # Запуск демона на порту 8081
   ./target/release/wasmee
   ```

2. **Запуск Go-сервера бенчмарков** (требует настроенного Go workspace):
   ```bash
   # Из корневого каталога воркспейса:
   go build -o connectors/wasmee/cmd/bench_server/bench_server connectors/wasmee/cmd/bench_server/main.go
   ./connectors/wasmee/cmd/bench_server/bench_server
   ```

3. **Запуск нагрузочного теста k6**:
   - **Прямой тест** (минуя Go-прокси, замер производительности чистого HTTP-сервера Rust):
     ```bash
     BENCH_SERVER_URL=http://127.0.0.1:8081 k6 run platform/loadtest/k6/wasm_rust_direct.js --vus 50 --duration 10s
     ```
   - **Тест через прокси** (замер Go-клиента с полной логикой загрузки стейта/oplog):
     ```bash
     BENCH_SERVER_URL=http://127.0.0.1:8085 k6 run platform/loadtest/k6/wasm_rust.js --vus 50 --duration 10s
     ```
